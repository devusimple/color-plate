# Color Plate 🎨

A curated collection of **30+ color palettes** following the **60-30-10 design rule**, built as a Progressive Web App. Generate harmonious color schemes, preview them on a live UI demo, and copy hex codes with one click.

## Features

- **30+ Handcrafted Palettes** — Light, dark, and warm themes ready to use
- **Random Palette Generator** — Generate harmonious palettes using color theory (analogous, complementary, triadic, split-complementary)
- **Live UI Preview** — See any palette applied to a realistic UI component
- **Component Mapping Guide** — Learn where to use dominant, secondary, and accent colors
- **One-Click Copy** — Click any color to copy its hex code
- **Filter by Mood** — Browse by Light, Dark, Warm, or Generated categories
- **PWA Ready** — Install as a standalone app on desktop or mobile
- **SEO Optimized** — Open Graph, Twitter Cards, and structured data included

## Usage

Open `index.html` in a browser, or serve with any static file server:

```bash
npx serve .
```

## PWA Installation

When visiting the site, a floating **Install App** button appears (supported browsers). Click it to install Color Plate as a standalone app.

## Tech Stack

- Vanilla HTML / CSS / JavaScript
- Inter font via Fontsource
- Service Worker for offline caching
- JSON-LD structured data for search engines
